# Bank Loan Repayment Risk Assessment System

A bachelor's project focused on assessing the risk of loan repayment using data analysis and machine learning.

## Project Scope

The initial selected scope is a focused, research-oriented system that estimates the risk of loan default for a loan applicant before a lending decision is made.

The system is intended to support human decision-making. It is not designed to make an automatic or final lending decision.
